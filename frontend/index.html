About

PlantTrack Pi is a Linux-based embedded validation and diagnostics framework targeting Raspberry Pi-class devices. It provides automated subsystem self-tests, real-time telemetry collection, fault injection for resilience testing, and rule-based root cause analysis — all accessible through a browser-based dashboard.

The system runs in simulation mode when real hardware is not connected, generating realistic telemetry values and fault scenarios. Extending to real hardware requires replacing the simulation service with actual system calls (v4l2, i2c-tools, df, ping).
